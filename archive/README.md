# Archived Assets

This directory contains legacy and exploratory files that are no longer part of the active Vite/React application build.

Contents:

- `471-glaceon-*.js` — early data-module experiments
- `masterset-*.js` — original PokeCottage widget implementations (binder, table, core, evolution)
- `pokemon-masterset-widgets.js` — embeddable widget script
- `pokecottage-page.html` — standalone HTML prototype
- `data-listing.txt` — scratch data listing
- `sample-large.webp`, `sample-png.png` — sample image assets

These files are retained for reference only. Do not import them into `src/` or include them in the Vite build.
